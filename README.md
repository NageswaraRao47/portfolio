# G. Nageswara Rao – AI Engineer & Technology Trainer Portfolio

A premium, interactive personal portfolio website built with **React**, **TypeScript**, **Tailwind CSS**, and **Lucide Icons** for **G. Nageswara Rao** (AI Engineer & Technology Trainer at **BRAIN O VISION – EdTech**).

---

## 🌟 Key Features

- **Futuristic & Dark Aesthetic**: Pure black & dark charcoal backdrops with electric blue, purple, and cyan neon glow effects and subtle cyber-grid textures.
- **Interactive Particle Background**: Real-time canvas particle network representing AI nodes and neural synaptic bridges.
- **10 Core Sections**:
  1. **Hero**: High-impact personal brand identity, custom avatar HUD, live specialization badge, CTAs, social profiles, and scroll indicator.
  2. **About Me ("Beyond Code. Into Innovation.")**: Professional narrative bridging cutting-edge AI research with college training.
  3. **Teaching Journey**: Verified timeline highlighting BRAIN O VISION role (May 2026 – Present) and the **10 Colleges Milestone**.
  4. **Technical Expertise**: 4 categorized interactive domains (Artificial Intelligence, Programming, Development, Frameworks & Tools) with live search and filter pills.
  5. **Workshops & Training**: Detailed cards for Generative AI, Agentic AI, Python, Bootcamps, and Hackathons, complete with an interactive session flow modal.
  6. **College Outreach**: Verified 10+ college campus metrics, classroom cards, and an in-browser photo replacement tool.
  7. **Teaching Philosophy**: 4 foundational pedagogical principles (*Learn by Doing*, *Real-World Demos*, *Simplifying Complexity*, *Interactive Learning*) with classroom analogies.
  8. **Featured Technical Projects**: Includes the flagship **Multi-Agent AI Assistant** with an interactive **live agent orchestration simulator**, plus Email Spam Detection and Real-Time Telegram Chatbot.
  9. **Connect With Me**: Direct links to LinkedIn, GitHub, a customizable email configurator with one-click copy, and a responsive inquiry/invitation form.
  10. **Footer**: Clean branding, BRAIN O VISION organization reference, 2026 copyright, and smooth back-to-top trigger.

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view the live website in your browser.

### 3. Build for Production
```bash
npm run build
```
Creates an optimized production bundle inside the `dist/` directory.

### 4. Preview Production Build
```bash
npm run preview
```

## 📸 How to Replace Photos with Your Actual Pictures

You have two easy ways to use your actual photos:

### Option A: Directly from the Website UI (Instant Preview)
- In the **Hero Section**, click the **"Click to replace with your photo"** button on the avatar card to test your portrait.
- In the **College Outreach Section**, hover over any workshop card and click **"Replace Photo"** to load your campus photographs.

### Option B: Permanent Code Configuration
1. Place your photo files into the `public/images/` directory (e.g. `public/images/profile.jpg`, `public/images/workshop-1.jpg`).
2. Open [`src/data/portfolioData.ts`](file:///c:/Users/Dell/OneDrive/Desktop/PORTFOLIO/src/data/portfolioData.ts).
3. Update the corresponding `customImageUrl` fields with `"/images/your-photo-name.jpg"`.
